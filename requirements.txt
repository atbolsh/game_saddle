# Core deep learning
# transformers >=4.60 references torch.float8_e8m0fnu (added in torch 2.7).
# The floor is torch >= 2.14: that release fixes the mem-efficient SDPA
# last-position bug (pytorch#191984, pytorch#192138, transformers#47651).
# torchvision 0.29.1 is the wheel published with torch 2.14 and accepts
# torch >= 2.14 (0.29.0 pins torch==2.14.0 exactly, so a 2.14.1 install
# would be forced back).
# 2.14 Linux wheels: cu126, cu130, cu132. There is no cu124 build.
# Driver >= 580 / Blackwell uses cu130 (or the default cu13 wheel):
#   pip install -U "torch>=2.14.0" "torchvision>=0.29.1" \
#       --index-url https://download.pytorch.org/whl/cu130
# A driver that only speaks CUDA 12.4 cannot install 2.14. A driver new
# enough for CUDA 12.6 uses the cu126 index instead.
# Kernel check, no Gemma weights: python scripts/torch_sdpa_residue_check.py

# Hugging Face ecosystem
# Gemma 4 requires a recent transformers (AutoModelForMultimodalLM, gemma4 arch);
# transformers 4.57.1 does NOT have AutoModelForMultimodalLM.
# The model registry's newest architecture (gemma-4-12b, `gemma4_unified`) was
# added in transformers 5.10.0, so that is the repo-wide floor. Models with a
# stricter need declare `min_transformers` in agent.model.MODEL_REGISTRY and
# fail fast with instructions if the installed version is older.
# Verified through 5.14.1 (the cap means "not yet verified past", 2026-07-30):
#   * gliner 0.2.28 declares transformers<5.14, so a FRESH resolve lands on
#     5.13.x with no conflict; manually forcing 5.14.1 alongside it was also
#     verified OK (healthy differentiated GLiNER scores -- its historical
#     transformers-v5 failure mode was uniform ~0.05 scores on every entity).
#   * The Gemma 4 left-pad corruption (transformers#47651) was the
#     mem-efficient SDPA kernel, fixed in torch >= 2.14, not in Gemma's
#     mask code. Do not bump this cap to chase that fix. After a
#     transformers bump, rerun scripts/torch_sdpa_residue_check.py and
#     GS_PAD_PARITY=1 python -m training.selftest t6.
